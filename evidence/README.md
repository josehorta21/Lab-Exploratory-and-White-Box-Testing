# Test evidence

After running the counter project on your own computer, save these actual screenshots here:

- `test-run.png` — terminal showing the completed `npm test` execution.
- `coverage-report.png` — terminal showing the completed `npm test -- --coverage` execution, with the App.tsx percentages visible.

Then update the coverage percentages and manual exploratory results in the root `README.md`. Do not use example or simulated test reports as evidence.

On macOS: press **Shift + Command + 4**, select the terminal region, and move the screenshot into this folder.
